# Planning

The planning package for this project, closed on 2026-11-21, before any code was written. It is
kept in the repository so the reasoning behind the design can be followed.

| Document | What it is |
| --- | --- |
| [01-decision-log.md](01-decision-log.md) | Every decision taken during discovery, with the options considered and the reason for the choice |
| [02-implementation-plan.md](02-implementation-plan.md) | The product summary, the project rules, the architecture, the data model, the ranking contract and the phases |

Both documents are a generic product specification. They name no person, employer or
application; anything of that kind lives outside the repository.

## How decisions change

The two documents above are a record of what was decided on that date and are not edited to
match later changes. A decision taken afterwards, or one that replaces an entry in the log, is
written as a short record in [`docs/adr/`](../adr/README.md) that says which entry it
supersedes.
